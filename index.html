How alerts are coloured

USGS assigns each volcano an aviation colour code from ground monitoring (seismicity, deformation, gas, webcams):

  • Green / Normal — background, non-eruptive state.
  • Yellow / Advisory — unrest above known background.
  • Orange / Watch — escalating unrest or minor eruption.
  • Red / Warning — hazardous eruption imminent or underway.
  • Magenta / NASA — a satellite-detected active event (EONET), independent of any ground alert level.
